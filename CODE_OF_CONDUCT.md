# Code of Conduct

## Our pledge

We want Blender-CamSight to be a welcoming project for people who report bugs, ask questions, and send patches. We pledge to keep interaction respectful for everyone involved.

## Expected behavior

- Be direct and specific about Blender versions, steps, and results.
- Assume other people are here to improve the add-on.
- Accept correction of code and docs without personal attacks.
- Give credit when you use someone else's work.

## Unacceptable behavior

- Insults, harassment, or sexualized language.
- Publishing someone else's private information.
- Sustained disruption of issues, discussions, or reviews.

## Enforcement

Report conduct problems through [GitHub private security reporting](https://github.com/axcel-blade/Blender-CamSight/security/advisories/new), or by contacting the maintainers listed on the repository. Reports are reviewed by the maintainers. Responses can include a warning or a block from the project spaces.

This project adapts the [Contributor Covenant](https://www.contributor-covenant.org/) version 2.1.
